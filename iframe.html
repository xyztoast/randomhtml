Browser Settings

Bypass Restrictions
Uses a proxy to load websites that usually block iframes (like Google). Note: Some features may break.
Allow Scripts
Lets the website run interactive parts like buttons and animations.
Allow Same Origin
Helps the website remember you and access its own internal files.
Allow Forms
Allows you to use search bars or login boxes on websites.
Allow Popups
Allows the website to open new windows or notifications.
Fullscreen Support
Lets videos expand to fill your entire screen.
